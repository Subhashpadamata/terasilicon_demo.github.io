## Formal Verification Subpage

The Formal Verification subpage uses the supplied `formal_verification(2).html` as the source of page content, terminology, service descriptions, methodology, use cases, proof-flow labels, CTA text, and footer text.

The existing Terasilicon IQ website header/navigation structure is preserved. The subpage styling is organized through the existing `css/` structure, with Formal Verification-specific styling in `css/10-formal-verification.css`.
